Privacy Policy, SecondBrain Sync

Last updated: November 24, 2026

What data is accessed

SecondBrain Sync accesses only the files that the app itself creates in the owner's Google Drive. Access is granted through the Google Drive API drive.file scope, which does not allow the app to see or change any other file in Google Drive.

How it is used

The app uses this access only to copy the owner's own notes to the owner's own Google Drive folder.

Storage and sharing

The app runs locally on the owner's computer. It has no server and no database. It does not collect, sell, share or transfer data to any third party. It does not use data for advertising and does not use data to train AI models.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The owner can remove the app's access at any time at myaccount.google.com/permissions. The owner can also delete the Google Drive folder that the app created.
