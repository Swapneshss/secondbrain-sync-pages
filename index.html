SecondBrain Sync

SecondBrain Sync is a personal tool that runs on the owner's own computer. It copies selected markdown notes from a local folder into a single folder in the owner's own Google Drive, using rclone.

What it accesses

The app uses the Google Drive API with the drive.file scope only. This scope lets the app see and change only the files and folders that the app itself creates. The app never reads any other file in Google Drive.

Who uses it

This is a personal, single-user tool. It is used by one person, the owner, and is not offered to the public.
